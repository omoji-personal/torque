This file contains links to LLM-friendly markdown documentation pages.

## Overview

Developer guide and API reference for the Salesforce GraphQL API, enabling developers to efficiently query and manipulate Salesforce records using GraphQL with support for field selection, record aggregation, schema introspection, and subscriptions as an alternative to REST and SOAP APIs.

## GraphQL API

Aggregate records, request explicit fields, introspect the schema, and more with GraphQL API for Salesforce. GraphQL is an open-source data query and manipulation platform for APIs.
