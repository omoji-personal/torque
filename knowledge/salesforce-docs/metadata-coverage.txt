# Metadata Coverage

This file contains links to LLM-friendly markdown documentation pages.

This file contains links to documentation sections following the llmstxt.org standard.

## Overview

Reference documentation for the Salesforce Metadata Coverage Report, used by developers and admins to determine which metadata components are supported across Metadata API, source tracking, managed packages, unlocked packages, and scratch orgs, covering API versions v47.0 through v67.0.

## Metadata Coverage Report

Determine supported metadata components across several channels, including Metadata API, scratch org source tracking, various types of packages, and more.
