## Overview

Documentation for Salesforce Code Analyzer, a free open-source static analysis tool for Apex, JavaScript, and Flow code that integrates multiple scan engines (PMD, ESLint, RetireJS, Flow Scanner, Regex, Salesforce Graph Engine) via Salesforce CLI, VS Code, and CI/CD to identify security, quality, and AppExchange compliance issues.

## Salesforce Code Analyzer

Boost your code quality with our free, open-source code scanner available through Salesforce CLI commands, Visual Studio Code (VS Code), and CI/CD.
